# Martian Map — Front End

واجهة React/Vite تفاعلية بطابع Mars HUD/Tablet لتخطيط مهمة في Gale Crater / Mount Sharp. هذا المستودع يحتوي الـFront End فقط؛ لا ينشئ أو يحاكي Back End تشغيليًا.

## التشغيل محليًا

```bash
pnpm install
pnpm dev
```

عنوان الـAPI الافتراضي هو `https://localhost:7215/api`. يمكن تغييره من إعدادات الاتصال داخل الواجهة، أو عبر متغير Vite `VITE_API_BASE_URL` قبل البناء. يحفظ الإعداد الذي يكتبه المستخدم في `localStorage` على ذلك المتصفح. عند فتح Preview من متصفح آخر، يلزم أن يكون عنوان الخادم قابلًا للوصول لذلك المتصفح، وأن يسمح الخادم بطلبات CORS من أصل الموقع وبشهادة HTTPS مقبولة.

## عقد التكامل المستخدم

يتصل العميل بالواجهات الواردة في دليل التكامل المرفق:

| الطريقة | المسار | الاستخدام |
| --- | --- | --- |
| `GET` | `/api/health` | حالة الخادم والنظام |
| `GET` | `/api/region` | اسم المنطقة، المصدر، نقطة الهبوط الاختيارية، الحدود الاختيارية والأهداف |
| `POST` | `/api/routes` | حساب المسارات للهدف ونقطة البداية المختارة |

يرسل طلب المسارات JSON بالشكل التالي، كما في دليل التكامل:

```json
{
  "start": { "lat": -4.92, "lon": 137.43 },
  "targetId": "boxwork-demo-1"
}
```

تقبل الواجهة الحقول المتاحة في دليل التكامل وأمثلة التقرير: بيانات الهدف العلمية، بيانات المسار و`path`، `distance_km`، `duration_min`، `max_slope_deg`، `avg_radiation`، `risk`، `elevation_profile`، وأقسام البيانات الحرارية/الطيفية/الجوية والمراجع البصرية. تُخفى مفاتيح الطبقات التي لا تصلها بيانات، وتعرض الواجهة الحقول الغائبة كغير متاحة.

يظهر في PDF أيضًا شكل مستقبلي/مقترح لـ`GET /api/targets/{id}` و`GET /api/layers` وملفات البلاطات `/static/layers/{layer_name}/{z}/{x}/{y}.png`. هذه المسارات ليست ضمن دليل التكامل الفعلي المرسل، ولذلك لا تُستدعى الواجهة تلقائيًا ولا تدّعي أن طبقات الصور الفضائية أو GeoJSON متاحة. الخريطة الحالية مخطط إحداثيات إسقاطي تفاعلي وليست صورة أقمار صناعية مسجلة جغرافيًا.

## بيانات المثال والسلامة

زر **عرض بيانات المثال** يحمّل بيانات اصطناعية موسومة بوضوح لعرض التفاعل فقط؛ لا تُرسل هذه القيم على أنها قراءات من الخادم. صورة Mount Sharp في هذا الوضع سياقية غير مسجلة جغرافيًا وليست صورة مستهدفة من مركبة جوالة. حقوق الصورة ومصدرها موثقان في [`docs/ASSET_CREDITS.md`](docs/ASSET_CREDITS.md).

ملخص Confirm Mission محلي للعرض ولا يرسل أمرًا للمركبة أو الخادم. المشروع أداة تخطيط توضيحية فقط، ولا ينبغي استخدام القياسات أو قيم المسارات لاتخاذ قرار سلامة تشغيلي.

## بناء الإنتاج

```bash
pnpm build
```

ينتج البناء الثابت في `dist/`. يحتوي إعداد Webdev الحالي على أمر تثبيت lockfile وبناء الإنتاج، دون نشر تلقائي للموقع.
