# Asset credits

## Mount Sharp context image

- Source: [NASA Science — Mount Sharp Inside Gale Crater, Mars](https://science.nasa.gov/resource/mount-sharp-inside-gale-crater-mars/)
- Credit as provided by NASA: NASA/JPL-Caltech/ESA/DLR/FU Berlin/MSSS.
- Description from NASA: an oblique view looking toward the southeast, derived from elevation and imaging data from three Mars orbiters. The resource describes the relationship of the mountain to Gale Crater and notes that the imagery combines elevation data from ESA Mars Express HRSC, image data from NASA Mars Reconnaissance Orbiter Context Camera, and color information from Viking Orbiter imagery.
- Use in this interface: an optional regional context image in the explicitly labelled sample-data mode only. It is not a target-specific rover POV, a basemap, or a georeferenced layer for drawing routes.
